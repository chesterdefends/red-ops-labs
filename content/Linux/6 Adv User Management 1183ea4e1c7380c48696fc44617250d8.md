Substituting Users and Doing as Superuser 

**A. Switching (or substituting) users

`su` command = switch into other user accounts (logs into root by default)

Ctrl+D = to exit user account  

**B. Doing as Superuser 

`sudo`  command = Provides normal users the ability to run an assigned set of privileged commands (or access non-owning files) as a superuser without root password. It is designed to provide protected access to administrative functions. 

`sudo` entries are defined in: ***/etc/sudoers*** file and ***/etc/sudoers/.d***  drop-in directory

Command to edit /etc/sudoers entries: `visudo` 

The sudo command logs successful authentication and command data to the ***/var/log/secure*** file under the name of the user who executed it (not root)
